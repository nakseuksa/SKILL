# 续读检查点：进度、知识围栏与理解状态

本模板用于用户要求保存进度或跨会话续读时。它不是自动记忆机制：只根据实际可访问的记录恢复上下文，不声称读过其他会话。未获保存指令时，可以在回复中提供简短检查点，不自动创建笔记。

## 保存与恢复规则

1. 先沿用用户指定的进度笔记；未指定时，按工作区约定保存，默认可用 `outputs/伍鸿熙 Pre-Algebra 阅读进度.md`。同名文件存在就先读取，只更新相关部分。
2. 只填写实际发生的阅读与反馈。用户自述、实际书页和助手推导应能区分；日期来自实际记录，不伪造过去的阅读历史。
3. 恢复时先确认材料定位、D/P/F/U 与未完成任务。记录中的来源仍缺失时，保留“待核实”，不把旧记录中的断言自动升级为原书证据。
4. 用户报告读到后面某节，不等于此前所有结果都已核验或掌握。也不必要求用户重证全部前文；对本次实际需要的依赖做最小核对即可。
5. “原书已建立”“在当前临时假设下成立”“读者已独立复述”是不同状态，分别登记。

```markdown

- 材料版本／文件：
- 小节与定位：注明纸书页、PDF 页或段落线索；不确定就不填页码。
- 本次实际完成：
- 下一段／下一题：
- 来源缺口：

## 当前知识围栏

| 分类 | 定义／结论／限制 | 依据与位置 | 使用状态 |
| --- | --- | --- | --- |
| D 已定义 |  |  | 原书已核验／用户允许／临时假设 |
| P 已建立 |  |  | 原书已核验／本次已证／用户允许 |
| G 待证 |  |  | 不得当作前提 |
| F 暂禁 |  |  | 后文／循环依赖／题目禁用 |

## 理解与复习

| 项目 | 数学上的建立状态 | 读者实际表现 | 下次检查 |
| --- | --- | --- | --- |

## 当前未完成事项

- 首个实质性断点或未解问题：
- 已给的提示层级：未提示／定向／动作／骨架／全解。
- 是否允许给全解：只按用户实际要求填写。
- 是否允许超前方法及适用范围：

## 下次从这里开始

- 一个最小动作：
- 需要补充的书页或定义：
```

## 回复中的简短版本

只需结束本轮、不必保存完整笔记时，可压缩为：

> **续读点**：本次材料……；已建立……；尚未核实……；当前提示到……；下次先……。

不要把“预计学会”“建议复习时间”写成已发生的学习记录，也不要声称后台已安排提醒。
