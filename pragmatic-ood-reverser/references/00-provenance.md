# 溯源标记规则与逆向剖析原文索引

## 1. 来源标记与证据纪律
- **`[§x.y]`**：直接源自原文（TC++PL 第四部分 23–25 章）的论断、原则或案例（含忠告 `[§23.7[36]]` 等）。
- **`[§x.y · 扩展]`**：以原文 `§x.y` 思想为锚点，结合 Java 17+ / TypeScript 服务端存量项目所做的逆向推演。
- **`[扩展]`**：原文未涉及、为适配 Spring Boot / Next.js 存量代码逆向工程新增的内容。
- **双锚定纪律**：架构判断给出**仓库相对位置与符号（`path/to/file:L10-L25`）**及上述一种方法论标记，P 编号可辅助索引。将源码事实、解释性推断、待验证项分开；没有项目证据不能靠书中原则补足。需核对原文措辞时，用 `grep` 检索 `references/source/part4.md`，**严禁整体读入 `part4.md`，严禁凭记忆编造原文引语**。
