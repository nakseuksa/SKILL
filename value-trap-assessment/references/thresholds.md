# 阈值、公式出处与证据等级

证据等级:**A** 监管或一手来源(已联网核实)· **B** 可复算 · **D** 学术模型(公式有出处,阈值多为实务惯例)· **E** 启发式,没有可靠出处。
**所有阈值都未经样本外校准,也没有任何已知的事前命中率。** GMO"价值陷阱每年跑输 9.5pp"衡量的是识别对了能避免多少损失,不能证明陷阱可以事前识别。

## 公式

| 指标 | 公式 | 出处 / 等级 |
|---|---|---|
| 合理 P/B | (ROE − g) / (r − g) | 剩余收益模型 · B。对 r、g 极度敏感,脚本输出 r±1%、g±1% 的敏感区间 |
| ROIC / CROIC | EBIT(1−t) / (净资产 + 有息债务 − 现金);FCF / 投入资本 | B |
| Sloan(现金流法) | (NI − CFO − CFI) / 平均总资产 | 实务变体 · D。Sloan (1996) 原文样本 1962–1991,用资产负债表法计算应计 |
| C-Score | 6 项二元测试(见脚本) | Montier (2008, SocGen) · D;分档 0–1 / 2–3 / 4–6 出处缺失 |
| M-Score | -4.84 + .920 DSRI + .528 GMI + .404 AQI + .892 SGI + .115 DEPI − .172 SGAI + 4.679 TATA − .327 LVGI | Beneish (1999) · D |
| F-Score | 9 项二元测试 | Piotroski (2000) · D |
| Altman Z(上市制造业) | 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4(市值/负债)+ 1.0X5 | Altman (1968) · D |
| Altman Z″(非制造业) | 6.56X1 + 3.26X2 + 6.72X3 + 1.05X4(**账面权益**/负债) | Altman · D |

## 唯一的一票否决:生存硬约束

满足任一条件即判"高陷阱风险":
1. 审计意见含持续经营重大不确定性;
2. 现金跑道 < 6 个月,且 18 个月内到期债务 > 现金 + 未用授信。

理由:这两种情况有明确的传导机制(被迫增发、债务重组、削减股息),不依赖未经校准的统计阈值。

## 已更正的常见引用错误(撰写报告时不得再犯)

| 错误说法 | 正确说法 |
|---|---|
| Piotroski 策略年化 23% | 23% 为多空组合;做多高分的超额约 7.5%/年 |
| Sloan 1996"40 年 18%" | 1996 年原文样本为 1962–1991;该数字出处不明 |
| Z″ 用 1.81 / 2.99 | Z″ 阈值为 1.1 / 2.6 |
| Beneish"标准阈值 -2.22" | 原文分界为 -1.78 |
| Brandes 研究证明"不要抄底" | 跌幅 ≥60% 的股票作为一篮子 3 年平均年化 11.2%(标普 4.6%),中位数落后 7.7%,约 9% 破产 |
| GMO 研究覆盖全球 | 基准为 MSCI US Value / Growth |
| S-REIT 杠杆 40% 即高危 | 监管上限为 50%;40% 是行业常见水平 |
| 连续 25 年增派可以排雷 | Walgreens 在近五十年连续增派后削减股息;IBM 1993 年削减过股息 |
| 调整后 EPS 尚可就是盈利尚可 | Walgreens Q1 FY24、Intel Q2 2024 的法定口径均为亏损 |
| 公司口径"调整后 FCF" | Intel Q2 2024 调整后 FCF 为 +82 亿美元(含合作方出资),CFO − 总资本开支约 −34 亿美元;必须注明口径 |
