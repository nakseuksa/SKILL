# 路由与指标豁免矩阵

先定路由,再算指标。路由选错会产生系统性误判。

| 路由 | 适用对象 | 判定提示 |
|---|---|---|
| `general` | 一般工商业 | 默认 |
| `cyclical` | 钢铁、化工、航运、航空、汽车、存储芯片、能源炼化、大宗资源 | 盈利随商品价格或行业景气大幅波动;过去 10 年至少出现一次 EPS 腰斩 |
| `financial` | 银行、保险、券商 | 资产负债表本身就是业务 |
| `reit` | REITs、商业信托 | 收益主要来自物业租金,有法定分配要求 |
| `utility` | 公用事业、电信、受管制基建 | 收费受管制,常态高杠杆 |

## 指标适用性

✅ 适用 · ⏭️ 豁免 · ℹ️ 只提示、不计分 · ⚠️ 阈值调整

| 指标 | general | cyclical | financial | reit | utility |
|---|---|---|---|---|---|
| 当期 / 远期 P/E | ✅ | ✅(远期大幅下滑是顶点信号) | ✅ | ℹ️(改用 P/AFFO) | ✅ |
| 正常化 P/E | ✅(结构性衰退时均值偏乐观) | ✅ **主依据** | ✅ | ℹ️ | ✅ |
| 合理 P/B 与 ROE − r | ✅ | ℹ️(须用周期中枢 ROE) | ✅ **主依据** | ✅ | ✅ |
| ROIC 趋势 | ✅ | ⚠️ 红旗降为橙 | ⏭️ | ✅ | ✅ |
| 营收连续两年下滑 | ✅ | ℹ️(价格波动) | ✅ | ✅ | ✅ |

| Piotroski F-Score | ✅ | ℹ️(顺周期) | ⏭️ | ✅ | ✅ |

## 各路由的人工补充检查(脚本不覆盖)

- **financial**:CET1 / 资本充足率、不良率与关注类贷款迁移、拨备覆盖率、存款结构与集中度、利率敏感性、保险业的准备金充足性。
- **reit**:WALE(加权平均租约期限)、出租率、租户集中度、固定利率债务占比、债务到期分布、所在司法辖区的杠杆上限。S-REIT 适用 MAS 2024 规则:50% 杠杆上限、ICR ≥ 1.5×、低于 1.8× 须制定改善计划。
- **cyclical**:目前处于周期什么位置(供需、库存、产能利用率、商品价格相对历史分位);底部期的亏损和营收下滑**不能**单独作为陷阱证据。
- **utility**:监管回报率机制、费率重设周期、资本开支计划能否进入费率基数。

## 周期股专用通道(解决终版报告 L3)

周期股的 F-Score、营收下滑、单期 ROE < r 都顺周期:顶点好看,底部难看。所以:
1. 以 **正常化 P/E**(≥5 年,最好覆盖完整周期)和 **远期 / 当期 EPS** 为主判断依据;
2. F-Score、营收下滑、ROE < r 只作提示,不能据此一票否决;
3. 真正的陷阱信号是:**周期均值盈利 ≤ 0**、**每轮周期的中枢 ROE 一轮比一轮低**、**底部期资产负债表扛不过去(生存硬约束)**。
