## 3. 六类诊断

每类写 2–4 句,引用脚本数值,并标注证据等级(A / B / D / E)。

1. **估值成因**:便宜来自暂时性挫折,还是结构性衰退?按正常化盈利看是否仍然便宜?
2. **资本回报**:ROE 与 r、ROIC 趋势、营收和毛利率走势。
3. **盈余质量**:Sloan、C-Score、M-Score 的结论,以及触发了哪些具体科目。
4. **边际动量**:F-Score 未通过的项目及其经济含义。
5. **生存能力**:Z 值、杠杆、利息覆盖、到期墙、现金跑道;是否触发硬约束。
6. **股息可持续性**:派息率、FCF 覆盖、股息率是否由股价下跌推升。

## 4. 定性检查

- 商业模式是否面临替代(技术、渠道、监管)?
- 资本配置:并购记录、回购时点、是否借"拯救型新业务"讲故事?
- 管理层与治理:激励结构、关联交易、审计师变更。
- 可验证的催化剂及时间表(没有就写"无")。

## 5. 反方论证(必填)

用最强的论据说明为什么这**不是**价值陷阱:有哪些证据支持"暂时性挫折、市场错杀"?体系可能在哪里误杀它?(周期底部、无形资产被费用化、一次性减值等)

## 6. 时机信号(仅参考)

盈利预测趋势、200 日线、内部人交易。说明这些信号不参与结论,并注明 Brandes 研究的结论:平均跑赢、中位数跑输。

## 7. 局限与未决

- 缺失的数据及其影响;
- 使用了启发式阈值(E 级)的结论;
- 需要后续跟踪的指标及复查时间(建议在下一期财报后)。
