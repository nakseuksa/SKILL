# 溯源标记规则与原文节号速查索引

## 1. 来源标记规则
- **`[§x.y]`**：直接源自原文（TC++PL 第四部分 23–25 章）的论断、原则或案例（如 `[§24.3.4]`、忠告 `[§24.5[15]]`）。
- **`[§x.y · 扩展]`**：以原文 `§x.y` 的核心思想为锚点，结合现代 Java 17+ / TypeScript 服务端特性所做的推演或改写。
- **`[扩展]`**：原文未涉及、为适配现代工程（如 Spring / Next.js 框架引力、ArchUnit / dependency-cruiser）新增的内容。
- **检索纪律**：需核对原文措辞时，用 `grep` 检索 `references/source/part4.md`，**禁止整体读入 `part4.md`，禁止凭记忆编造原文引语**。
